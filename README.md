# System Projects

Central repository for Arturo Ruiz's AI system projects.

## Repository structure

Each system should live under its own stable folder:

```text
systems/
  <system-name>/
    <version>/
```

Development and installation work may happen on dedicated `system/<name>-<version>` branches before being merged into `main`.

## Current systems

System folders will be added here as they are installed and reviewed.
