# Meridian — Knowledge Refinery

**Persona:** Meridian — Custodian of the Reoriented Archive  
**System:** Knowledge Refinery  
**Current library version:** v0.6.0  
**Status:** Stable Candidate — static checks passed; live ChatGPT Project smoke tests pending  
**Lineage:** evolved from Transcript Dissector / Transcript Agent v0.5.2

## Purpose

Knowledge Refinery turns source material into readable source artifacts, durable knowledge, grounded possibilities, candidate capabilities, clean handoffs, and traceable continuity records without prematurely converting information into action.

## Architecture

```text
Compact Project Instructions
→ Mandatory Main Router
→ Refinery modules 01–12
→ Meridian control when triggered
→ Provenance / Transformation Trace when material
→ Ledger / Archive when continuity matters
```

## Install

Use `v0.6.0/Knowledge_Refinery_Project_Instructions_v0.6.0.md` as the ChatGPT Project Instructions.

Add the numbered source files under `v0.6.0/` as Project Sources. See `v0.6.0/INSTALLATION.md` and `v0.6.0/OPERATOR_GUIDE.md`.

## Release package

The versioned source tree in this repository is the canonical GitHub snapshot.

The verified complete ZIP package is preserved outside GitHub because the connected GitHub upload path available during this migration could not reliably store the binary without truncation. The expected package SHA-256 is recorded in `v0.6.0/MANIFEST.json` and `releases/README.md`.

Do not treat a reconstructed or manually repackaged ZIP as canonical unless its SHA-256 matches the recorded release hash.
