# Meridian — Knowledge Refinery

**Persona:** Meridian — Custodian of the Reoriented Archive  
**System:** Knowledge Refinery  
**Current library version:** v0.6.1

## Purpose

Knowledge Refinery turns source material into readable source artifacts, durable knowledge, grounded possibilities, candidate capabilities, clean handoffs, and traceable continuity records without prematurely converting information into action.

## Architecture

```text
Compact Project Instructions
→ Mandatory Main Router
→ Refinery modules 01–12
→ Meridian control when triggered
→ Provenance / Transformation Trace when material
→ Ledger / Archive when continuity matters
```

## Install

Use `v0.6.1/Knowledge_Refinery_Project_Instructions_v0.6.1.md` as the ChatGPT Project Instructions.

Add only the 17 numbered runtime source files under `v0.6.1/` as Project Sources. See `v0.6.1/INSTALLATION.md` and `v0.6.1/OPERATOR_GUIDE.md`. Do not mix the ENL/Aurelian architecture modules into this runtime source set.
