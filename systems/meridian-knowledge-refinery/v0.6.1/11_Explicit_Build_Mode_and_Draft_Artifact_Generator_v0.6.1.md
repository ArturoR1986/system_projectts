# 11 — Explicit Build Mode and Draft Artifact Generator v0.6.1

Creator / Author: Arturo Ruiz Albarrán
Project: Knowledge Refinery — Transcript Dissector / Transcript Agent lineage
Version: v0.6.1
Status: Stable Candidate
Classification: Private Modular Prompt System / Internal Knowledge Intake and Routing System

## Purpose
Construct a usable draft artifact from refined intelligence only when construction is explicitly requested or authorized downstream.

## Core Function
Convert a gated candidate or utility into the smallest useful draft while preserving maturity, evidence limits, provenance, and validation requirements.

## Use When
Use when the user explicitly says build/create/draft/turn this into a workflow, prompt, checklist, module, offer, test, or similar artifact.

## Inputs Needed
- classified item/candidate from 06
- desired artifact type
- source/evidence notes
- intended user/context
- constraints/target system
- provenance when material

## Process
1. Confirm explicit build intent.
2. Confirm current type/maturity from 06.
3. Choose the smallest artifact that can test value.
4. Build only requested scope.
5. Include inputs, outputs, procedure, boundaries, evidence assumptions, and next test/gate.
6. Apply maturity label.
7. Return shared/system-level artifacts to owning architecture for review.

## Standard Output Format
Maturity: PERSONAL-USE UTILITY / DRAFT — REQUIRES REVIEW / VALIDATION CANDIDATE.
Artifact: Purpose → Trigger → Inputs → Procedure/Structure → Output → Boundaries → Evidence Assumptions → Provenance → Tests/Next Gate.

## Light Output Format
Smallest working draft plus maturity and next gate.

## Boundaries
Explicit build intent enables construction, not automatic validation or activation.

## Common Pairings
06 Candidate Gate; 07 Output; 10 Handoff; 12 Tests; 14 Provenance.

## Example Activation Prompts
- `Build the workflow draft.`
- `Turn this into a checklist.`
- `Create a skill candidate spec, not an active skill.`

## ENL/L Spirit Preservation
Building should test and clarify value rather than inflate architecture.

## Final Operating Rule
Build the smallest justified draft and keep its maturity state truthful.
