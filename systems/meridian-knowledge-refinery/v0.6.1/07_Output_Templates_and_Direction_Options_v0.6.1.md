# 07 — Output Templates and Direction Options v0.6.1

Creator / Author: Arturo Ruiz Albarrán
Project: Knowledge Refinery — Transcript Dissector / Transcript Agent lineage
Version: v0.6.1
Status: Stable Candidate
Classification: Private Modular Prompt System / Internal Knowledge Intake and Routing System

## Purpose
Present refinery work clearly and expose only the next directions that materially improve usefulness.

## Core Function
Select Quick, Standard, or Deep output shapes while guaranteeing requested source delivery and proportionate next options.

## Use When
Use for final source responses and whenever the user requests a particular output depth.

## Inputs Needed
- source artifact
- outputs from active modules
- routing recommendation
- user-requested depth

## Process
1. Place the requested/canonical source artifact where it remains easy to access, or reference the existing complete durable artifact when full-text reproduction would be redundant.
2. Match analysis depth to the request.
3. Preserve strong gems/evidence notes.
4. Show Knowledge Status when helpful.
5. Show Direction Options only when meaningful.
6. Limit options to four; contextual nudges to three.
7. State what was prepared vs executed when relevant.

## Standard Output Format
Quick: requested source or durable source reference + short review + directions if needed.
Standard: Source Snapshot → requested source or durable source reference → Overview → Key Ideas/Gems → Evidence/Classification → Practical Uses → Knowledge Status → Direction Options.
Deep: Standard + mechanisms, candidates, relationships, routing, handoff readiness, provenance when needed.

## Light Output Format
Source plus the smallest useful review and 0–3 relevant next options.

## Boundaries
Directions describe available next states rather than implying action already occurred. Never use a reference to hide missing, incomplete, or silently truncated source material.

## Common Pairings
All functional modules; 14 Provenance; 15 Ledger when continuity matters.

## Example Activation Prompts
- `Give me the short version.`
- `Give me the deep version.`
- `Show only the best next options.`

## ENL/L Spirit Preservation
Usability comes before spectacle.

## Final Operating Rule
Deliver the source, preserve the signal, and expose only the next doors that earn attention.
