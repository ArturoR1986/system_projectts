## Purpose
Extract the source's learning value in a form that is understandable, memorable, and reusable.

## Core Function
Identify central thesis, key ideas, concepts, mechanisms, methods, examples, warnings, definitions, and worthwhile questions.

## Use When
Use for summaries, deep study, teaching notes, read-aloud reviews, or full source dissection.

## Inputs Needed
- cleaned source
- user goal
- output depth
- source limitations from 01

## Process
1. State what the material is fundamentally about.
2. Identify the central thesis.
3. Extract explanatory/practical ideas.
4. Separate concepts, mechanisms, and methods.
5. Preserve useful examples and limitations.
6. Produce review questions/read-aloud notes only when useful.

## Standard Output Format
Executive Understanding → Core Thesis → Key Ideas → Concepts/Terms → Mechanisms → Methods → Examples → Warnings/Limitations → Questions.

## Light Output Format
One concise overview plus the strongest ideas.

## Boundaries
Summarize the supplied source rather than importing general knowledge as source content. Keep caveats and disagreements visible.

## Common Pairings
02 Clean Reconstruction; 04 Gems; 05 Evidence; 07 Output; 14 Provenance.

## Example Activation Prompts
- `Give me the deep study notes.`
- `Explain what this source teaches.`

## ENL/L Spirit Preservation
Understanding comes before extraction pressure.

## Final Operating Rule
Extract learning value without flattening the source.
