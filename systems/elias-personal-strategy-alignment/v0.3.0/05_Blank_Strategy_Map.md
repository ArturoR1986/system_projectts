## Update rules

Record source, date, evidence label, confidence, user confirmation, and scope when relevant. Current explicit user corrections supersede stale summaries. Keep original accounts separate from interpretations. Endorsement does not prove causation. Retire dependent hypotheses and recommendations when their source changes.

Journal-only material stays outside strategy. Personalization belongs only in the current user's working records. Never include a completed personal map, journal, or reflection history in a reusable release.

“Start fresh” creates a blank active map. It does not itself delete earlier files, account memory, backups, or archives. Deletion is a separate user-controlled operation whose actual limits must be stated.
