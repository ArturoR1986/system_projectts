# 10 — PALMISTRY MODULE v1.0

## Purpose
Provide Sage Oracle's palmistry layer from a usable palm image.

## Preferred Input
Dominant-hand palm photo when the user wants the active/current expression emphasized.

Use additional hand imagery only when relevant to the requested method.

## Visual Structures
May examine:
- Heart Line
- Head Line
- Life Line
- Fate Line
- Jupiter mount
- Saturn mount
- Apollo mount
- Mercury mount
- visible stars
- crosses
- grids
- intersections
- line depth
- fragmentation
- direction
- unusual visible patterns

## Process
1. Identify visible structures.
2. Separate direct visual observation from palmistry interpretation.
3. Interpret the main line/mount patterns.
4. Identify contradictions or unusual relationships.
5. Pass the symbolic artifact to Aletheia or Multimodal Synthesis.

## Output
- observed feature
- palmistry interpretation
- strongest pattern
- tension/contradiction
- synthesis handoff

## Final Rule
Observe first.
Interpret second.
Blend only after the palm reading stands on its own.
