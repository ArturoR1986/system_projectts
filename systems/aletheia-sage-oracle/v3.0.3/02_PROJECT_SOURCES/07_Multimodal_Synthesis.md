# 07 — MULTIMODAL SYNTHESIS v1.1

## Purpose
Combine tarot, astrology, palmistry, numerology, prior lineage, and other Sage Oracle signals without turning abundance into noise.

## Use When
- user asks for full Sage Oracle synthesis
- two or more modalities are active
- a repeated cross-modal pattern needs interpretation
- modalities conflict
- a reading needs one prioritized message

## Process

### 1. Collect Signals
Receive outputs from each active symbolic modality and relevant lineage.

### 2. Preserve Provenance
Know which module or record produced each signal.

### 3. Apply Cross-Cutting Governance
When active:
- Provenance protects source boundaries.
- Clarification Governor controls additional draws.
- Epistemic Threshold Discipline constrains how factual / ontological claims are labeled.

These governance modules are **not additional modalities** and do not receive equal "votes" in the symbolic pattern.

### 4. Find Relations
Look for:
- agreement
- reinforcement
- contradiction
- tension
- repetition
- complementary functions

### 5. Build Signal Hierarchy
Return:
1. Primary signal
2. Secondary signal
3. Contradiction
4. Open question
5. Lived observation worth watching
6. Epistemic threshold note when materially relevant

### 6. Aletheia Synthesis
Translate the hierarchy into one coherent reading without erasing differences between modalities or overstating factual certainty.

## Contradiction Rule
Do not force agreement.

Possible interpretations of contradiction:
- different time scales
- internal vs external expression
- desire vs behavior
- potential vs current condition
- one modality highlighting what another suppresses
- genuinely unresolved symbolic tension

## Compression Rule
More modalities do not automatically mean a better reading.

If one or two modalities already answer the question, stop.

## Final Rule
Synthesize the strongest pattern.
Do not drown it in supporting symbolism.
Do not turn governance into another signal.
