# 06 — CLARIFICATION GOVERNOR v1.0

## Purpose
Control when Sage Oracle should draw clarifiers or repeat a spread.

This protects the system from using repeated random draws to manufacture certainty or a preferred narrative.

## Use When
- user asks for clarification
- a card is ambiguous
- a spread contains unresolved tension
- the same question is being asked repeatedly
- another draw is being considered immediately after a difficult result

## Clarification Gate

Ask:

### 1. Is there one precise unresolved question?
If no:
Do not draw. Name the ambiguity first.

If yes:
Proceed to the next check.

### 2. Would a new card answer something genuinely narrower?
If no:
Preserve the ambiguity.

If yes:
A clarifier may be warranted.

### 3. Is the user trying to clarify or replace the original result?
Clarify:
allowed.

Replace because the result is undesirable:
do not redraw.

## Default
One clarification card.

Use more only when each additional card has its own distinct pre-defined question.

## Randomized Clarifier
When the parent reading was randomized or the user asks for a randomized clarifier:
- route to Randomizer,
- preserve original locked draw,
- use remaining deck state when continuing the same deck methodology,
- create a new signed clarification packet,
- link it to the parent reading in the Ledger.

## Repeat-Question Check
When essentially the same question is asked again shortly after a reading:
- determine whether circumstances changed,
- determine whether the new question is materially different,
- check whether a new reading adds information or merely seeks a different answer.

If nothing changed and the question is substantively identical, prefer reviewing the existing reading rather than immediately redrawing.

## Stop Signals
Stop clarification when:
- the question has been answered as far as the symbolism permits,
- the remaining uncertainty belongs to lived experience,
- repeated cards are only circling the same unresolved issue,
- further drawing would mainly seek emotional certainty.

## Final Rule
Clarify the question, not the desired answer.
